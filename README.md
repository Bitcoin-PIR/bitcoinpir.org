# bitcoinpir.org landing page

Static landing page served by GitHub Pages at https://www.bitcoinpir.org/.
The query app lives at https://app.bitcoinpir.org/ (built from
Bitcoin-PIR/Bitcoin-PIR `web/`). `reproduce.html` here only forwards old
links to the app's copy.

Fonts: PT Sans Narrow and PT Serif (ParaType, SIL Open Font License 1.1),
latin subsets self-hosted in `fonts/` so the page loads nothing from third
parties.
